## 上流の探索比較

既存体型2の9入力を6候補で再処理した54回の探索。推定済みSAM結果を固定している。
同じcacheを使う候補間比較であり、通常pipelineとの一致は別途確認する。

|変更|距離差 %|方向と3倍の余裕|
|---|---:|---:|
|48枚の対照|3.491|9/9|
|観測サイズでlossを正規化|3.509|9/9|
|＋肩・腰の2D landmark拘束|2.631|9/9|
|＋全frameの骨格を共通化|0.370|9/9|
|さらにbounded yawを調整|0.400|9/9|

共通化前はfitでframeごとの骨格サイズを使い、出力でのみ共通骨格を使っていた。
fitと出力で同じ骨格を使う候補を選定した。正規化だけの改善、yaw追加の優位性は
支持されなかった。これは候補の組合せの比較で、実人体での因果性・精度の証明ではない。

cacheの対照は旧出力に対して最大約0.48 model mmのずれがあり、0.1mmの一致基準を
満たさなかった。TorchのCPU poolとbatch計算を変えており、この差を隠さず記録する。
探索結果だけで採用せず、通常pipelineの再計算と候補選択に使っていない体型3で確認する。

frame選択は48枚のSAM推定を行った後にfitへ使う16/32/48枚を比較した。
初期shapeの推定には48枚を使うため、encoderの計算削減や16枚だけの撮影を検証した
扱いにはしない。

## 通常pipelineと別体型での結果

通常pipelineは計28回、20件復元、8件の診断を伴うQC拒否、例外停止0、未完了0。
探索81回（上流54＋sampling27）は保存したSAM推定の再fitであり、28回とは区別する。
同じ動画の再処理を含み、109本の独立した撮影ではない。

|比較|結果・判断|
|---|---|
|共通骨格候補・体型2|同じ距離動画の差3.488%→0.352%。基準3本の最大差は1.582→2.430 model mmへ悪化|
|輪郭の再抽出|＋40の反応23.35→20.87 model mm、時間約1.8倍。残差改善だけでは採用しない|

|同入力・同候補の再実行|頂点はbit一致、周長差0。開始角度や別体型への安定性とは別の確認|

体型3の＋10の推定変化は3.45〜5.23 model mm、ばらつきの3倍は5.32 model mm。
＋20や＋40にも過小反応が残る。fitと出力の骨格不一致は修正可能な設計上の問題だったが、
これだけで小さい信号の観測限界・shapeへの写像・実人体精度が解決したとはいえない。
