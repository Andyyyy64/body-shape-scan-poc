# 測定アルゴリズムの改善・実装計画（2026-10-03）

目的は、輪郭残差を小さくすることではなく、同じ体型の再撮影を安定させつつ、
既知の腹部変化を過小推定せず復元すること。既存の研究候補を対照に原因を分離する。
この文書は実行中の計画。診断と候補の実装・探索を進めているが、最終採用条件はまだ未達。
[前段の実施済みTODO](improvement-plan.ja.md)とは区別する。

## 現在の構造と確認済みの症状

`pipeline.py`は各frameのSAM shapeの中央値を初期値とし、45次元のshared shapeをfitする。
`contours.py`は初期meshを整数pixelでrasterizeし、外周に近いmesh頂点と観測mask外周を
それぞれ256点へ抽出する。`shared_shape.py`は両方向の最近傍距離、shape prior、camera prior、
選択したlandmark拘束を最適化する。対応する最近傍は各評価で変わるが、mesh外周に使う
頂点集合・局所pose・観測maskは原則固定。

出力は共通骨格のcanonical mesh。`mesh.py:section_perimeter`が、profileに保存した
断面と内部seedを通る閉曲線の周長を読む。初回断面は肩・腰の間の32%の位置で、
以後は同じ座標を使用する。これは実測したへそ位置やウエストではない。

|確認した事実|解釈の限界|
|---|---|
|体型3の同seedで＋10→＋4.798、＋20→＋10.178、＋40→＋20.507 model mm|この範囲では約半分の反応。原因は未確定|
|体型3の基準最大差1.772 model mm、＋10の余裕0/3、距離差1.034456%|方向が合っても測定の安定性・距離基準は未達|
|体型1の3D直接fitで＋10→全身6.866／torso8.823／腹部帯9.655 model mm|腹部重視なら表現可能な例がある。画像fitの精度や全体型での上限の証明ではない|
|弱いshape priorと腹部重みで反応は増えた|prior等の影響は示唆されるが、最新候補の原因分離は未実施|
|輪郭再抽出で残差は減ったが周長の反応は悪化|pixel residualだけを採用条件にできない|

3D直接fitは元の体型1、最新の過小推定は軸変形した体型3である。同一条件の結果として
割り算せず、最新profile・骨格・断面で再診断する。新しいcapacity診断は生成元とキャッシュのhashを検証し、体型3も対象にする。
座標の異なる真形状は、診断専用の肩・腰登録で比較する。正解形状は推定へ渡さない。

## 原因仮説と切り分け順序

優先順位は以下。2〜5の変更は一度に混ぜない。

|順序|仮説|反証可能な比較|その結果から選ぶ実装|
|---|---|---|---|
|1|評価断面・座標系の違いが反応を変えている|同じmeshに同じ断面を適用し、断面を±5 model mm変えた周長感度も診断|定義の不一致なら座標変換・profile生成を修正|
|2|現行shapeの表現力か、全身への目的関数配分が不足|最新条件で3D直接fitと、モデル内の既知shape変化を比較|表現可能なら現行モデルを維持。表現不足なら局所basisを検討|
|3|初期shapeへのpriorが真の変化を抑える|同じ観測・初期値でpriorだけ変更し、目的関数成分と周長を比較|priorの尺度とlossを修正|
|4|camera／poseの調整がshapeと交換可能|camera固定・深度固定・現行freeを比較し、shapeとcameraのJacobianの重なりを調べる|自由度を段階的に解くsolverへ変更|
|5|mask・輪郭抽出の量子化や外周頂点の固定が小信号を失う|理想の浮動小数輪郭、rasterized mask、実推定maskの順で劣化量を比較|signed-distance型の輪郭lossと画像上の境界refinementを比較|

`sqrt(d² + 4)`は小さい距離でも微分可能で、2px未満を無視する閾値ではない。
小信号域では勾配が弱くなるため、priorとの相対強度を測る。ここだけを原因と断定しない。
またSAM由来の2D landmarkと3D anatomyには誤差の相関があり、独立した実測拘束とは扱わない。

## 0. 評価基準を固定する

最初の実装は診断の入口と評価manifest。旧実験は探索用として保持し、再利用する体型3を
新しいholdoutとは呼ばない。新候補を見てからseedや閾値を変えない。

- 原因の最小再現は同じseedのbaselineと＋10。＋20／＋40、既存基準3本、距離2条件へ広げる。
- response gain＝推定周長差／真の周長差を、各変化・体型・seed別に保存する。
- 診断探索は1round最大8候補。初回は0／±10／±20／＋40と開始角度・距離の対照を含む
  最大10入力で比較し、成分変更を順次選ぶ。キャッシュfitは速度優先の探索と明記する。
- 最終検証用の新しい合成条件は、探索を始める前にmanifest・renderer版・入力hashを固定する。
  3体型×5seed×6変化量＝90本の良好動画に、距離対18本と悪条件12本を追加する。
  変化量は0／−10／＋10／−20／＋20／＋40 model mm。距離対は3体型×3seed×2距離。
  既に使った体型でも、検証用seedは未使用として探索から隔離する。
- 悪条件12本は3体型×4条件（人物だけのぼけ、ぼけ＋noise、遮蔽、回転不足）を事前固定する。
- 最終pipeline比較は選定した1候補と対照を同じ120本で実行する。
  多数の候補全てへ高価なSAM推定を繰り返さない。

既存の通常処理は約2分／本なので、240回の比較は現在の速度でも約8時間を要する。
solver変更でさらに増える可能性があるため、探索で候補を絞ってから行い、1caseごとに
結果を保存して再開可能にする。既存のinference lock、network isolation、RSS上限・
空きメモリguardを維持し、モデルworkerを並行起動して速度を稼がない。

合成実験の採用目標は、各体型で基準最大差≤2 model mm、±10を含む方向一致と
基準差の3倍超を各seedで満たし、各変化のgainが0.8〜1.2、各距離対の対称差≤1%。
良好動画の受理率≥90%、悪条件は事前に宣言したQC拒否を満たす。QC拒否で感度の失敗を
分母から消さない。現行候補より悪くなる項目は、その数値を併記して採用判断する。
これは提案した合成目標であり、人体の10mm精度を保証する基準ではない。

seedごとにbaselineと変更動画を両方用意する。過去の1変更動画×3baselineは
3つの独立した変更撮影ではない。frameを独立標本とした信頼区間は作らない。

## 5. 局所shapeを追加する：診断が支持する場合だけ

対象：新設予定の`local_shape.py`、`fit_strategy.py`、canonical mesh生成・method version。

3D直接fitでも腹部のgainが足りない、または画像に合う方向が現行basisにない場合に着手する。
腹部の前後幅・左右幅を高さ方向に滑らかに変える少数のbasisを追加し、肩・腰の接続部では
変位を減衰させる。頂点対応・閉曲面・周長定義を保ち、自己交差、極端な変形、腹部外の漏れを検査する。
生成器の同じdeform関数をそのまま推定器へコピーして成功する比較にはしない。
別種類の変形でも検証し、model_mmを人体のmmへ読み替えない。

局所basisを足すと観測できない自由度が増える。bounds、smoothness、識別可能性の検査を必要とし、
nullと悪条件のfalse changeが増える場合は不採用。大規模再学習は、この段階でも必要性を示せない
限り着手しない。

## 6. 寸法の不確かさと最終検証

対象：新設予定の`measurement_diagnostics.py`、`pipeline.py`、`synthetic_evidence.py`。

独立した再撮影と開始角度・輪郭摂動で周長の安定性を評価する。これはモデル感度の診断値であり、
校正済みの人体の信頼区間として表示しない。単なるimage sharpnessだけでは、良好画像からの
不安定な寸法を止められないため、識別不能な場合は数値を確定しない研究QCを比較する。
受理率と感度を併記し、全拒否で合格する仕組みにしない。

選定後の通常pipeline比較では入力hash・method・モデル・コードsnapshot・QC・時間・メモリを保存し、
既定v1の回帰と既存テスト、隔離・lock・メモリ制限を確認する。
syntheticのみで成立した段階では、通常Soma測定へ採用しない。

実人体の最終確認には、同一人の独立した撮り直し、距離・衣服・姿勢の変更、独立した基準測定が必要。
絶対寸法の確認には尺度の校正も必要で、共通骨格による比較だけでは人体のcm精度を保証できない。
これらの入力が必要な段階までは、上記の診断・実装・合成比較を自律的に進められる。

## 実行中の結果と次の判断

自律作業の達成条件は上記の合成採用目標と通常pipeline・回帰検証。
達成検証、ユーザーからの停止指示、または外部入力・実行基盤の継続的な阻害を停止条件とする。
固定round数の終了や改善失敗を達成・停止理由にしない。外部投稿・pushは実施しない。

- 目的関数の成分・パラメータ別勾配、初期／最終周長、断面±5 model mm診断を実装。
- FP32のMM版Euclidean `torch.cdist`は同じ画像座標でも最大0.25pxを返す最小再現を確認。
  direct版を研究候補へ実装。既知モデル内の±10 model mmはgain約0.998で復元した。
  ただし体型3の実推定観測では＋10→約4.817のため、この数値問題だけでは説明できない。
- priorの変更、固定prior尺度、camera固定／深度固定、step増加、robust loss変更を比較。
  いずれも感度・再撮影・距離の全条件を満たしていない。
- 同じSAM結果にRGB GrabCutを適用すると体型3の＋10反応は約7.229へ増えたが、
  基準最大差も約3.500へ増え、距離差約1.242%で未達。
- 肩・腰登録を行った3D直接fitでは腹部帯のgain約0.969が得られたが、
  係数norm約30.95／最大約18.56を要した。通常のprior範囲で十分とは断定しない。
- 生成器と異なる滑らかな腹部の左右／前後残差basisと共通初期shapeを実装。
  比較8候補では＋10への反応は増えた例があるが、基準最大差は約3.368〜6.814で未達。
  局所変形だけを増やす候補は現時点で採用しない。
- 推定された局所関節poseと初期shapeをprofileへ共通化し、共有深度、局所残差を比較。
  体型3では＋10の反応約9.487まで増えた候補があるが、基準最大差約3.010で未達。
  体型2では基準最大差・距離も未達で、単一体型の感度改善を採用扱いしない。
- SAMの2D keypointは3D jointとcameraの投影であることを実装から確認。
  別の画像観測として固定checksumのYOLO11s-poseを実装した。信頼度を保存し、
  画像外・低信頼度をfitへ使わない。独立していることと寸法精度が高いことは別。
- 新設したroot傾き補正の回転規約に実装ミスを検出。SAM headの表現をそのまま
